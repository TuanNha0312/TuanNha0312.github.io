GA4 Data API là gì? Cách lấy số liệu Google Analytics 4 bằng code

Tuấn Nhã · 28/09/2026

Google Analytics 4 (GA4) đếm số người vào website và việc họ làm sau khi vào. Bình thường ta xem các con số này trên giao diện web của Google Analytics. GA4 Data API là cách để một chương trình tự hỏi Google những con số đó, không cần mở trình duyệt, nhờ vậy có thể tự động làm báo cáo hằng ngày hoặc hằng tuần.

Ba khái niệm cần nắm

Property ID là dãy số định danh một property GA4, xem trong Admin → Property details. Mọi yêu cầu đều ghi dạng properties/123456789.

Dimension là thứ dùng để chia nhóm dữ liệu, ví dụ date (ngày), landingPage (trang đích), sessionDefaultChannelGroup (kênh: Organic Search, Direct, Referral…).

Metric là con số được đếm, ví dụ sessions, totalUsers, engagementRate, keyEvents.

Một yêu cầu runReport trông như thế nào

Yêu cầu cơ bản nhất gồm property, khoảng ngày, dimension và metric. Ví dụ lấy số phiên theo ngày trong 28 ngày gần nhất:

{
  "dimensions": [{ "name": "date" }],
  "metrics":    [{ "name": "sessions" }],
  "dateRanges": [{ "startDate": "28daysAgo", "endDate": "yesterday" }]
}

Muốn chỉ lấy traffic từ tìm kiếm tự nhiên (SEO) thì thêm bộ lọc sessionDefaultChannelGroup = "Organic Search".

Một vài lưu ý

Ngày trả về có dạng chuỗi YYYYMMDD, cần chuyển sang kiểu ngày khi xử lý. Không phải cặp dimension và metric nào cũng dùng chung được, nên thử trước bằng công cụ GA4 Query Explorer của Google. API có hạn mức (quota) theo property, vì vậy nên gộp truy vấn thay vì gọi lặp lại nhiều lần.

Một điều mình gặp khi thử: tài khoản demo Google Merchandise Store xem được trên giao diện, nhưng gọi qua API thì bị từ chối (lỗi 429). Muốn thử API thì phải dùng property GA4 của website do chính mình quản lý.

Bài liên quan: Search Console API, tạo service account.
