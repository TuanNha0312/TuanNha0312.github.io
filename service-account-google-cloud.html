Service account Google Cloud là gì và cấp quyền cho GA4, Search Console

28/09/2026

Khi một chương trình cần gọi API của Google mà không có người ngồi bấm đăng nhập, ta dùng service account: một tài khoản dành riêng cho chương trình, có email dạng ten@du-an.iam.gserviceaccount.com.

Các bước tạo

Vào Google Cloud Console, tạo một project. Trong APIs & Services → Library, bật Google Analytics Data API và Google Search Console API. Vào IAM & Admin → Service Accounts, tạo service account, sau đó vào tab Keys → Add key → JSON để tải file khóa về.

Cấp quyền

Service account giống một người dùng mới, phải được mời vào thì mới xem được dữ liệu. Trong GA4: Admin → Property access management, thêm email của service account với vai trò Viewer. Trong Search Console: Settings → Users and permissions, thêm email đó với quyền Restricted.

Giữ file khóa cẩn thận

File JSON là chìa khóa đăng nhập của chương trình. Không đưa nó lên GitHub, không gửi qua nhóm chat. Nên thêm tên file vào .gitignore ngay từ đầu. Nếu lỡ để lộ, vào Google Cloud xóa khóa đó và tạo khóa mới.
